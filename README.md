## 📖 Sobre o Projeto

A Biblioteca Arcanjo é um sistema CRUD (Create, Read, Update e Delete) criado para permitir o gerenciamento de uma coleção pessoal de livros de forma simples e intuitiva.

O projeto foi desenvolvido utilizando apenas tecnologias front-end, armazenando os dados localmente através do LocalStorage do navegador, sem necessidade de banco de dados externo.

Além das funcionalidades básicas de cadastro e gerenciamento de livros, o sistema conta com recursos de busca, filtros, organização dos registros e personalização da biblioteca.

---

## 🚀 Funcionalidades

### 📚 Gerenciamento de Livros

- Adicionar novos livros
- Editar informações de livros cadastrados
- Excluir livros
- Visualizar catálogo completo
- Armazenamento automático no navegador

### 🔍 Pesquisa e Organização

- Busca por título
- Busca por autor
- Busca por gênero
- Filtro por categoria
- Ordenação por autor
- Ordenação por ano

### ⭐ Recursos Extras

- Avaliação dos livros por estrelas
- Cadastro de capa dos livros via URL
- Estatísticas da biblioteca
- Interface amigável e responsiva

### 👤 Login Local

- Identificação simples do usuário
- Armazenamento do nome via LocalStorage
- Personalização da experiência
