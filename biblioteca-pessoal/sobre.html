Sobre o Projeto

Conheça a história, as tecnologias e as pessoas por trás da Biblioteca Arcanjo Pessoal

O que é este projeto?

A Biblioteca Arcanjo é um mini site desenvolvido como trabalho acadêmico, com o objetivo de praticar os fundamentos do desenvolvimento web front-end: HTML semântico, CSS moderno e JavaScript puro com manipulação da API DOM.

O tema escolhido foi uma biblioteca pessoal digital — um gerenciador de livros onde o usuário pode registrar títulos, acompanhar seu progresso de leitura e manter tudo organizado diretamente no navegador, sem necessidade de backend.

"Uma sala sem livros é como um corpo sem alma."
— Marco Túlio Cícero

Os dados são armazenados no LocalStorage do navegador, o que significa que suas informações persistem entre sessões sem precisar de servidor ou banco de dados externo.

Objetivos de Aprendizagem

Este projeto foi desenvolvido para atingir os seguintes objetivos técnicos:

  • ✓ HTML semântico — uso correto de elementos como nav, main, section, footer, article
  • ✓ CSS personalizado — variáveis CSS, Grid, Flexbox, animações e design responsivo
  • ✓ JavaScript puro — API DOM direta, sem frameworks. Manipulação de eventos, criação dinâmica de elementos
  • ✓ CRUD completo — Create, Read, Update e Delete com persistência no LocalStorage
  • ✓ Navegação multi-página — menu e rodapé compartilhados em todas as páginas
  • ✓ Imagem local — ilustração SVG hospedada no próprio projeto

Tecnologias Utilizadas

Desenvolvido apenas com tecnologias web nativas

🌐

HTML5

Estrutura semântica com elementos modernos: nav, main, section, article, footer e atributos ARIA.

🎨

CSS3

Estilização com variáveis CSS, CSS Grid, Flexbox, animações @keyframes e design responsivo.

⚡

JavaScript Puro

API DOM nativa sem frameworks. Manipulação de eventos, criação dinâmica de elementos e LocalStorage.

💾

LocalStorage

Persistência dos dados no navegador do usuário. Os livros ficam salvos entre sessões automaticamente.

🖼️

SVG

Gráfico vetorial escalável criado localmente e usado como imagem na página inicial do projeto.

🔤

Google Fonts

Tipografia com Playfair Display (títulos) e Inter (corpo de texto), carregadas via CDN.
